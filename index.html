Dialer / CRM domains

Users on these domains (or any subdomain of them) count as tracking, not idle, even with no mouse/keyboard activity — for softphone/dialer tools where they're on a call rather than typing. Changes here take effect for users within a few minutes, with no extension update or reload needed.

Extension version

After rolling out a new build to agents, raise this to that version to force everyone still on an older one off it — a below-minimum extension is blocked from starting new sessions, and an already-running session is stopped automatically within a minute. Leave blank (or set to 0.0.0) to allow any version.

Activity scoring ceilings

The activity % shown per agent and stored on every sample is mouse/keyboard event counts scored against these per-minute ceilings (100% = at or above the ceiling). The defaults (90 mouse, 60 keyboard) are starting guesses, not measured — pull a range of real activity_samples for your team (Reports tab, or query the table directly) and set these to what real, focused work actually looks like for your agents' roles. Leave either blank to use the extension's built-in default for that channel. Takes up to 5 minutes to apply to already-running sessions (cached client-side).

Add a user type

A user type controls which dashboard tabs an account can see, whether it can edit or only view each of those tabs, and — separately — which users' data it's allowed to see at all. Owner and Admin are protected and can't be edited or deleted here — both always see and edit everything. Creating, editing, resetting passwords for, or deleting user accounts on the Dashboard tab is always Owner/Admin only — no custom user type can be given that ability; custom user types can still be given view access to the Dashboard tab to see the team list. The User Management tab (this one) additionally breaks down into sections below — a user type can be given, say, Tasks but not User Types itself.
Check a tab to make it visible. For tabs with an "Edit" option, leave it unchecked to give this role read-only access to that tab.
Restricts every tab above to just these users' data (Dashboard, Timesheets, Reports, Leads, Flags). Owner and Admin always see everyone regardless of this setting. Check as many of the first three as you like — they combine (e.g. "Only themselves" + "A specific user type" together). "All users" is exclusive since it already includes everyone.

ReadyMode

ReadyMode's Integrations team confirmed their API is lead-oriented only — Call Logs, Research Calls, and Agent/Productivity data isn't available via API. Two ways to get it in here instead: (1) automatically, via a ReadyMode Automated Task that emails a CSV on a schedule — see "Automated email imports" below; or (2) manually, by downloading a CSV from ReadyMode's Reports screen and pasting it into the boxes below. Note: ReadyMode's Productivity Report itself has no export option — use the Agent Report instead, which covers the same ground (Ready/Break time, calls made, etc.).

Agent → ReadyMode mapping

Match each Agent user to their ReadyMode username so their calls, research lookups, and productivity stats are attributed to them.

Import ReadyMode reports (CSV)

Paste the CSV contents from each ReadyMode report's "Download CSV" button, then click Import. Safe to re-import — matching rows are updated, not duplicated.

Automated email imports

Set up a ReadyMode Automated Task (Call Logs and/or Agent Report) to email its CSV to your Mailgun inbound address on a schedule, and Mailgun forwards it straight to the readymode-email-import function — no manual pasting needed. Full setup steps are in READYMODE-INTEGRATION.md. This table shows every import attempt so you can tell at a glance whether an email arrived and parsed correctly.
