Import a list

Paste a CSV that has already been scrubbed in ReadyMode. Automated imports arrive by email through dialer-list-import; this is the manual path for a one-off file.

Lists

Imported contacts are not dialable until validated — the calling-hours gate needs each number's own time zone, which only Number Lookup can resolve. Validation also drops disconnected numbers before you spend a dial on them, and ranks mobiles ahead of landlines.

Validate in batches, not whole lists. At $0.0015 a number, a 100,000-contact import costs $150 to validate up front — mostly on numbers that will not be dialled for a year. Validating 500 at a time costs 75¢ and keeps agents supplied; top it up as the Unvalidated count falls.
